Liquid Glass Lab

Liquid Glass は背景を 屈折させて少しだけ拡大する ことで「厚みのある透明なレンズ」を表現します。 中央はわずかな倍率変化、エッジは強い屈折 + Fresnel。blur は控えめで、背景の情報量を中央に残します。 CSS Frosted (blur のみ) との違いは Grid / Pattern シーンではっきり分かります。
